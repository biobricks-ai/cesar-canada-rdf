# cesar-canada-rdf

Streaming RDF transformation for Canadian CEPA/CMP assessment and prioritization
records from ECCC and Health Canada. Conclusions, statuses, prioritization terms,
and dates are source-qualified Canadian records, never universal hazards.

n-Hexane has two independent records: a final screening assessment concluding
that it does not meet CEPA section 64, and a finalized Challenge batch 4 health
categorization. Source data are licensed under the Open Government Licence Canada.
